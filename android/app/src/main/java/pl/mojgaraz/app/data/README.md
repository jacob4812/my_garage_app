# Warstwa danych

Warstwa danych jest przygotowana jako miejsce dla przyszłych adapterów Supabase/PostgreSQL oraz lokalnego cache Room. W ETAPIE 1 nie zawiera połączeń, modeli danych ani operacji zapisu.

Supabase pozostanie źródłem prawdy, a operacje zmieniające ilości będą dodane dopiero razem z atomową obsługą po stronie serwera i RLS.
